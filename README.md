# CANVAS - Animation & Multimedia Club Website

## Overview

A university front-end development project for an Animation & Multimedia Club website.

The website provides information about the club, its activities, projects and members through an interactive and responsive web interface.

## My Contribution

This was a university group project. My main responsibility was developing the **Gallery and Projects** section of the website.

I worked on:

* Designing and developing the Gallery section
* Implementing the Projects section
* Creating interactive project and gallery components
* Implementing search, filtering and sorting functionality
* Handling browser-based data storage
* Testing the responsiveness and functionality of the pages

## Technologies

* HTML5
* CSS3
* JavaScript
* Fetch API
* Local Storage
* Session Storage

## Key Features

The website includes:

* Responsive web design
* Interactive gallery
* Project showcase
* Search and filtering
* Sorting functionality
* Form interaction
* Browser-based data storage
* Interactive user interface

## My Section

The Gallery and Projects section allows users to:

* Browse multimedia content
* Search for projects
* Filter project information
* Sort displayed content
* View project details through interactive components
