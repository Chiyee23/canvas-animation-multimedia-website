# CANVAS - Animation & Multimedia Club Website

## Overview

A university front-end development project for an Animation & Multimedia Club website.

The website provides information about the club, its activities, projects and members through an interactive and responsive web interface.

The version uploaded to this repository is an **improved version of the original group coursework**, with additional refinements and improvements made to the overall website.

## My Contribution

For the original group project, my main responsibility was developing the **Gallery and Projects** section of the website.

After completing the group coursework, I further improved the overall website by refining and enhancing different sections and components.

My work included:

* Designing and developing the Gallery section
* Implementing the Projects section
* Creating interactive project and gallery components
* Improving the overall website layout and user interface
* Refining responsive design across different pages
* Improving JavaScript functionality and interactions
* Implementing search, filtering and sorting functionality
* Handling browser-based data storage
* Testing and improving the overall website functionality
